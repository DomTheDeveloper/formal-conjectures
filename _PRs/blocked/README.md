# Blocked

This directory is for problems that are not currently close enough for `almost-ready/` because of a fundamental mathematical, semantic, migration, provenance, or trust blocker.

Examples include an essential admitted dependency, a historical proof that no longer compiles and requires a broad rewrite, or a duplicate result already solved upstream.

Move a record to [`../almost-ready/`](../almost-ready/) only after a concrete and credible path to the final readiness gates exists.
