# Queue

This directory is for newly identified or untriaged work only.

Once a problem has been assessed:

- move it to [`../almost-ready/`](../almost-ready/) when it is close enough to track but still missing one or more gates;
- move it directly to [`../ready/`](../ready/) only when every readiness gate is already green;
- move it to [`../blocked/`](../blocked/) when it is not currently close enough for the promotion pipeline.

Do not leave actively classified near-finish problems in `queue/`.
